# AHMAG curator bot

Личный Telegram-бот: собирает материалы, отбирает их по вкусу канала AHMAG, пишет посты в трёх форматах и публикует в одном из трёх режимов — от полностью ручного до автомата.

## Меню

`/menu` (или `/start`). Сверху — расписание дня, каждый слот строкой:

```
Сегодня, 17.09
✅ 10:00 ст   · Дом в Киото // Tato Architects
🟡 13:00 ст   · Павильон из обожжённого кедра
🕑 16:00 мини · вариантов на выбор: 3
🤖 19:00 ст   · автопост: Капелла в Граубюндене
⚪️ 21:30 ст   · пусто

Завтра: 🟡⚪️⚪️⚪️⚪️
```

✅ вышел · 🟡 стоит ваш пост · 🤖 автопост · 🕑 присланы варианты · ⚪️ пусто · ⏭ пропуск · ✖️ прошёл пустым.

Под расписанием — кнопки слотов. Нажатие открывает слот: пустой — «🎯 Подобрать варианты сейчас» и «⏭ Пропустить»; занятый — «👁 К карточке» и «↩️ Освободить»; вышедший — ссылка на пост в канале. «Завтра ▸» показывает следующий день, «🔄 Обновить» перерисовывает меню (само сообщение не обновляется).

Ниже: режимы (активный отмечен точкой), **▶️ Следующий пост / ▫️ Мини-пост**, **📝 #ahmagnotes**, **🔄 Собрать сейчас**, **📊 Статистика / 📈 Итоги недели**, **📡 Источники**, **⏸ Пауза**.

**Пост по ссылке:** пришлите боту любую ссылку — он соберёт из неё пост (порог оценки не применяется, но оценка и замечания будут в карточке).

## Форматы

| Формат | Что это | Фото |
|---|---|---|
| **стандарт** | заголовок, 1–2 абзаца, кредиты, теги | 4–10 |
| **мини** | заголовок, по желанию одна фраза, теги | 1–4 |
| **#ahmagnotes** | заметка 1500–2800 знаков, только по запросу | до 10 или без фото |

Формат выбирает Claude при оценке: стандарт — когда есть мысль, мини — когда материал говорит сам. Кнопка **↔️** на карточке переключает стандарт ⇄ мини без нового обращения к Claude. Если мини-постов в очереди нет, а стандартных больше шести, бот сжимает один из них (лучшие четыре не трогает).

## Слоты и режимы

Слоты задаются переменной `SLOTS`, по умолчанию 4 стандартных и 1 мини:
`10:00=std,13:00=std,16:00=mini,19:00=std,21:30=std`. Мини можно добавить сколько угодно: `…,12:00=mini,17:30=mini`.

Пост привязывается к конкретному слоту. В любом режиме на карточке:

- **⏱ Ближайший слот** — одно нажатие: слот, к которому пост предложен, иначе ближайший свободный его формата;
- **🗓 Выбрать слот** — список свободных слотов на ближайшие дни (≠ помечен слот другого формата — поставить можно, решение ваше);
- **🔀 Перенести** (у поста, который уже стоит) — в другой свободный слот или ⇄ поменяться местами с другим постом.

Если слот прошёл, а пост не вышел (пауза, перезапуск), он выходит в ближайшем слоте своего формата или переносится в свободный — ничего не теряется.

- **Ручной** — как раньше: карточки приходят в часы `DELIVERY_HOURS`, до `DAILY_MAX` в день. Слоты публикуют только то, что вы сами поставили в очередь.
- **Полуавтомат** — за `SLOT_LEAD_MIN` минут до слота бот присылает `SEMI_OPTIONS` вариантов. «⏱ Ближайший слот» поставит пост именно в этот слот, «✅ Опубликовать» — сразу. Ничего не выбрали — слот пропускается, варианты возвращаются в очередь. Пост, не выбранный `MAX_OFFERS` раз, снимается.
- **Автомат** — за `SLOT_LEAD_MIN` минут до слота бот присылает анонс: «🤖 Автопост в 14:00». Не отменили — выйдет сам. В автомат попадают только посты с оценкой от `AUTO_MIN_SCORE`, без замечаний (⚠️) и не из источников, которые вы чаще отклоняете, чем одобряете. Если такого поста нет, бот присылает варианты, как в полуавтомате. Слот, где уже стоит ваш пост, автомат не трогает. Слот с пометкой «пропуск» не заполняется.

## Карточка

Альбом с подписью — ровно как выйдет в канале, под ним сообщение с оценкой, форматом, источником и кнопками:

- ✅ Опубликовать · ⏱ Ближайший слот · 🗓 Выбрать слот;
- ✏️ Свой текст · 🔁 Переписать (по комментарию, с учётом формата);
- 🖼 Фото — убрать отдельные кадры, выбрать обложку (альбом в чате не перестраивается, в карточке видно, сколько фото уйдёт);
- ↔️ В мини / В стандарт;
- ❌ Отклонить — с причиной; причины учитываются при следующих оценках.

После публикации на карточке остаётся **📸 Пакет для Instagram**: оригиналы фото файлами, без сжатия Telegram, и подпись простым текстом.

## #ahmagnotes

1. Кнопка → 5 тем на выбор (или своя). Темы не повторяют архив и уже предложенное.
2. Бот собирает материал через веб-поиск Claude и показывает **главную мысль, план и источники**.
3. «✏️ Поправить план» — комментарием; «✅ Писать» — бот подбирает фото (страницы-источники + Wikimedia Commons), пишет заметку и присылает обычную карточку с источниками для проверки.

Веб-поиск должен быть включён для API-ключа в консоли Anthropic. Если он недоступен, бот соберёт материал без него и предупредит в карточке.

## Надёжность

- Режим, пауза, очередь, источники — в SQLite на volume, перезапуск ничего не сбрасывает. База старой версии мигрирует сама.
- Сбой в задаче расписания приходит вам сообщением (не чаще раза в час на задачу).
- `DAILY_API_CALLS_MAX` — потолок фоновых вызовов Claude в сутки. Кнопки (переписать, ссылка, notes) под лимит не попадают.
- Файлы решённых постов удаляются через `IMAGE_TTL_DAYS` дней.
- По воскресеньям в `DIGEST_HOUR` приходит дайджест: что вышло, доля одобрений по источникам, причины отказов, расход API. Просмотры и реакции канала Bot API не отдаёт — их в дайджесте нет.

## Структура

```
main.py              запуск, расписание, уведомления об ошибках, очистка
app/config.py        настройки из переменных окружения
app/db.py            SQLite: кандидаты, посты, настройки, расход API, заметки
app/sources.py       источники (RSS встроенные и добавленные, Met API)
app/media.py         извлечение статьи, скачивание и фильтр фото        (без изменений)
app/commons.py       поиск фото в Wikimedia Commons для заметок
app/curator.py       промпты и вызовы Claude: оценка, переписывание, notes
app/formatter.py     сборка подписи по формату, нормализация тегов
app/pipeline.py      кандидат → пост; пост по ссылке; заметка; выбор следующего
app/cards.py         карточка, клавиатуры, публикация, пакет для Instagram
app/slots.py         слоты и режимы
app/reports.py       тексты меню, статистики, дайджеста
app/notes.py         сценарий #ahmagnotes
app/bot.py           меню, кнопки карточки, команды, ссылка
data/                профиль вкуса и архив канала                         (без изменений)
```

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SLOTS` | `10:00=std,13:00=std,16:00=mini,19:00=std,21:30=std` | расписание публикаций |
| `SLOT_LEAD_MIN` | 30 | за сколько минут до слота присылать варианты / анонс |
| `SEMI_OPTIONS` | 3 | вариантов на слот |
| `AUTO_MIN_SCORE` | 8 | порог оценки для автомата |
| `MAX_OFFERS` | 2 | сколько раз предлагать пост |
| `DAILY_API_CALLS_MAX` | 150 | потолок фоновых вызовов Claude в сутки |
| `NOTES_WEB_SEARCHES` | 6 | поисковых запросов на одну заметку |
| `MIN_PHOTOS_MINI` / `MINI_MAX_PHOTOS` | 2 / 4 | фото для мини-поста |
| `IMAGE_TTL_DAYS` | 14 | хранение файлов решённых постов |
| `DIGEST_DOW` / `DIGEST_HOUR` | sun / 20 | недельный дайджест |
| `DAILY_MAX` | 10 | карточек в день в ручном режиме |
| `DELIVERY_HOURS` | 10,14,19 | когда присылать карточки в ручном режиме |
| `SCORE_THRESHOLD` | 7 | порог оценки |
| `COLLECT_EVERY_HOURS` | 4 | частота сбора |
| `MAX_PER_RUN` | 12 | материалов за проход |
| `MET_PER_RUN` / `MET_DAILY_MAX` | 2 / 2 | музейные объекты |
| `CLAUDE_MODEL` | claude-sonnet-5 | модель |

Обязательные: `BOT_TOKEN`, `ADMIN_ID`, `CHANNEL_ID`, `ANTHROPIC_API_KEY`, `DATA_DIR=/data` (volume).
