# AHMAG curator bot

Личный Telegram-бот, который собирает материалы из источников, отбирает их по вкусу канала AHMAG, пишет готовые посты и присылает их на модерацию. Одобренные посты бот публикует в канал от своего имени.

## Как это работает

1. **Сбор** (каждые `COLLECT_EVERY_HOURS` часов). RSS ArchDaily, Dezeen, designboom, Colossal и открытая коллекция The Met.
2. **Фильтр.** Нужно не меньше 300 знаков текста и не меньше 4 фото (для музейных объектов достаточно одного). Длинная сторона фото от 1200 px, дубли и странные пропорции отсекаются.
3. **Claude** оценивает материал по `data/ahmag_taste_profile.md` с учётом эталонов из `data/ahmag_posts.json`, стоп-листа, ваших недавних отказов и одобрений. При оценке 7 и выше пишет пост и выбирает порядок фото.
4. **Выдача** в часы `DELIVERY_HOURS`, всего до `DAILY_MAX` карточек в день. Сначала идут посты с высокой оценкой, с поправкой на баланс рубрик.
5. **Карточка:** альбом, текст поста, оценка, источник и кнопки
   - ✅ Опубликовать — альбом с подписью уходит в канал;
   - ✏️ Свой текст — пришлите текст целиком, форматирование сохранится;
   - 🔁 Переписать — Claude переписывает по вашему комментарию;
   - ❌ Отклонить — выбор причины; причина учитывается при следующих оценках.

Команды: `/next`, `/collect`, `/stats`, `/cancel`.

## Структура

```
main.py              запуск, расписание
app/config.py        настройки из переменных окружения
app/db.py            SQLite: кандидаты и посты
app/sources.py       источники (RSS, Met API)
app/media.py         извлечение статьи, скачивание и фильтр фото
app/curator.py       промпт и вызовы Claude
app/formatter.py     сборка подписи в формате AHMAG, нормализация тегов
app/pipeline.py      кандидат → готовый пост; выбор следующего
app/bot.py           карточки, кнопки, команды
data/                профиль вкуса и архив канала
```

## Запуск на Railway

1. Залейте папку в новый репозиторий GitHub и создайте на Railway проект из этого репозитория.
2. **Volume:** Service → Settings → Volumes → Add, mount path `/data`.
3. **Variables** (образец в `.env.example`):
   - `BOT_TOKEN` — токен от @BotFather;
   - `ADMIN_ID` — ваш Telegram ID (@userinfobot);
   - `CHANNEL_ID` — `@username` канала или его числовой ID `-100…`;
   - `ANTHROPIC_API_KEY`;
   - `DATA_DIR=/data`.
4. Бот должен быть администратором канала с правом публикации.
5. Deploy. После старта напишите боту `/start`, затем `/collect`. Первый сбор занимает несколько минут: за один проход обрабатывается до `MAX_PER_RUN` материалов.

Локальный запуск: `pip install -r requirements.txt`, заполнить `.env` (например, через `export`), `DATA_DIR=./data_local python main.py`.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DAILY_MAX` | 10 | карточек в день |
| `DELIVERY_HOURS` | 10,14,19 | когда присылать (по `TZ_NAME`) |
| `SCORE_THRESHOLD` | 7 | порог оценки |
| `COLLECT_EVERY_HOURS` | 4 | частота сбора |
| `MAX_PER_RUN` | 12 | сколько материалов оценивать за проход (влияет на расход API) |
| `CLAUDE_MODEL` | claude-sonnet-5 | модель |

## Добавить источник

RSS: добавить строку в `FEEDS` в `app/sources.py`. Другой тип источника: написать функцию по образцу `collect_met` и добавить её в `COLLECTORS`.
