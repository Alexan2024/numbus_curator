# Правки записей сайта

Сюда кладутся правки того, что уже лежит на theahmag.com: опечатка в заголовке, английский текст, имя автора,
запись, которую надо убрать. Каждая правка — отдельный файл `ГГГГ-ММ-ДД-коротко-что.json`.

Как это доходит до сайта: файл попадает в GitHub → Railway перезапускает бота → через полторы минуты бот
применяет новые файлы (по порядку имён, каждый один раз), пересобирает сайт, выкладывает изменившиеся
страницы и присылает отчёт. Файл с ошибкой бот пропускает целиком и пишет почему; исправленную правку кладут
под новым именем — старое имя бот уже запомнил. Вёрстка (`site/web`, `prerender.js`, `sitebuild.py`)
выкладывается так же, без файлов правок.

## Формат

Поля записей — те же, что в данных сайта (https://theahmag.com/data.json). Поле заменяется целиком,
`null` убирает поле. Номер записи (`id`) не меняется.

Исправить заголовок записи:

```json
{
  "comment": "опечатка в названии",
  "objects": {
    "1234": {"t": {"ru": "Дом у реки", "en": "House by the River"}}
  }
}
```

Убрать запись или заметку с сайта (страницы удаляются, ссылки на неё пропадают):

```json
{"objects": {"1234": null}}
```

Поправить имя в указателе или страну (новым нужны `ru` и `en`; у людей можно задать `roles`):

```json
{
  "people": {"tadao-ando": {"ru": "Тадао Андо", "en": "Tadao Ando"}},
  "countries": {"croatia": {"ru": "Хорватия", "en": "Croatia"}}
}
```

Разделы: `objects`, `notes` (ключ — номер), `people`, `countries` (ключ — id), `comment` (для себя).
Люди и страны, на которые больше не ссылается ни одна запись, исчезают сами.

## Проверить до выкладки

На свежих данных с сайта: применить правку и собрать сайт локально (`sitebuild.build`), — бот делает то же
самое. Если запись ссылается на имя или страну, которых нет в указателе, правка не применится.
